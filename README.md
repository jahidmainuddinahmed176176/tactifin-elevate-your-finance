# Tactifin - Islamic Finance Platform

## Tech Stack
- React 19 + TanStack Router + TanStack Query
- Supabase (Auth + PostgreSQL)
- Tailwind CSS + shadcn/ui
- Vercel AI SDK + Gemini AI

## Features
- Dark/light mode toggle
- Email + Google authentication
- Dashboard with charts
- Income/expense tracking (auto haram detection)
- Budget management
- Savings goals
- Bill Pay (bKash/Cash on Delivery)
- Islamic compliance checker
- Zakat, Tax & Credit score calculators
- AI chatbot (Gemini)
- Learning resources with progress tracking
- Financial tips & news
- Newsletter subscription


## Links
- **Live Site:** https://tactifin-elevate-your-finance.vercel.app/
